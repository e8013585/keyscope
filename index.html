Does KeyScope sell, generate or crack Windows keys?

No. KeyScope only shows a key that is already stored on the PC you run it on. It doesn't create keys, sell them, or bypass activation, and a Technician License doesn't include a Windows license.

Will KeyScope change anything on my PC?

No. It only reads. It never writes to the registry or firmware and never touches Windows activation. It doesn't need administrator rights.

Does it send my key anywhere?

No. Reading your PC's information happens entirely offline. The only time KeyScope goes online is when you activate, check or deactivate a Technician License, and then it sends only that license key and a random label for the installation. See the privacy policy.

Why doesn't KeyScope show a key on my PC?

Many PCs don't store a personal key. Windows that was upgraded or activated with a digital license often holds only a generic key, which is the same for everyone and identifies no purchase. KeyScope tells you when that's the case instead of guessing.

Do I need a Technician License?

Only if you use KeyScope for work: for an employer, in a business, or as part of paid services such as setting up or repairing other people's computers. Personal use at home is free.

Which edition should I download?

On Windows 10 version 1809 or later and Windows 11, use KeyScope. On Windows 7 SP1 or 8.1, on 32-bit Windows, or if you want a single 2 MB file, use KeyScope Classic.
